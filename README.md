# coordinate_conversion
A simple perl script to convert the input coordinates from the latest assembly GRCh38 to GRCh37.

This script uses the Ensembl Core API - http://asia.ensembl.org/info/docs/api/core/core_tutorial.html

Usage: coordinate_converter.pl <chromosome_number> <start_coordinate> <end_coordinate>
Example: coordinate_converter.pl 10 25000 30000
